# Retry Analyzer

Desktop-приложение для массового анализа Wi-Fi capture-файлов (`pcap`, `pcapng`, `cap`) и расчёта Retry Rate.

**[Скачать последнюю версию](https://github.com/melvilsky/Retry-Analyzer-Releases/releases/latest)**

## Возможности

- Анализ файлов в выбранной папке и подпапках.
- Автоматический выбор основного клиента и направления трафика.
- Таблица результатов, MCS-статистика и логи обработки.
- Параллельная обработка файлов.
- Экспорт результатов в CSV.
- Открытие capture-файла в Wireshark.

Для обычного анализа Wireshark и TShark не требуются: движок анализа входит в приложение. Для открытия capture-файлов в Wireshark установите Wireshark отдельно.

## Установка

Откройте [Releases](https://github.com/melvilsky/Retry-Analyzer-Releases/releases) и выберите доступную сборку в разделе **Assets**:

- **Windows x64, portable `.zip`**: распакуйте весь архив и запустите `retry_ui.exe` из распакованной папки. Установка не требуется. Сохраняйте остальные файлы рядом с приложением.
- **macOS Apple Silicon, `macos-arm64.dmg`**: откройте образ и перетащите `Retry Analyzer.app` на папку **Applications / «Программы»**. Затем извлеките образ и запускайте приложение из «Программ».
- **macOS Apple Silicon, `macos-arm64.zip`**: альтернативная сборка; распакуйте архив и переместите `Retry Analyzer.app` в папку «Программы».

Архивы **Source code**, которые GitHub показывает автоматически, содержат только файлы этого публичного репозитория. Приложение нужно скачивать из прикреплённых сборок выше.

Сборки macOS пока не подписаны сертификатом Developer ID и не прошли нотариализацию Apple. macOS может потребовать подтверждение первого запуска.

## Аналитика

Приложение может отправлять анонимные события использования. Пути к папкам, имена файлов и MAC-адреса не передаются. Отправку можно отключить через иконку статистики в шапке приложения.

Этот репозиторий содержит описание и готовые релизы. Исходный код хранится отдельно в приватном репозитории.
